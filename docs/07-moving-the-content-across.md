# Moving the content across from HostGator

The old site is built with HostGator's own website builder. There is no export from it into a
usable format, so this is a copy and paste job. That is fine, and it has a silver lining: it
forces a review of what is actually worth keeping.

## Before anything else, save the pictures

Text is quick to retype. Photos are not recoverable once the hosting is gone.

Either right click and save each image from the live site, or use the File Manager in the
HostGator control panel to download the whole images folder at once. The control panel route
is faster and gets the full size originals rather than whatever the page happens to display.

## Then copy the text

For each page worth keeping:

1. Open the old page in one tab and `gigicollective.com/admin` in another.
2. Create the matching Page or Blog post.
3. Copy the text across. Paste as plain text (Cmd Shift V) so the old site's formatting does
   not come with it, then apply headings and bold in the editor.
4. Upload the pictures for that page as you go, rather than all at the end. Easier to keep
   track of which image belongs where.

## Decide what not to bring

Most sites that have been running a while have pages nobody has looked at in years. This is
the moment to drop them. Fewer, better pages is better for Google than lots of thin ones.

Rough rule: if it has had no visits in a year and it is not the About or Contact page, leave
it behind.

## Keep the web addresses the same where you can

If the old About page was at `gigicollective.com/about-us`, name the new page so it lands on
`gigicollective.com/about-us` too. That way Google keeps whatever ranking it already has.

The address comes from the title. A page titled "About Us" becomes `/about-us`
automatically. If a title has to change, set up a redirect instead. See
`docs/04-hosting-and-domain.md`, section 3d.

## Order to do things in

1. Copy the content across while the old site is still live, so you can compare side by side
2. Check the new site over on a phone as well as a laptop
3. Point the domain at the new site
4. Wait a week and make sure nothing is missing
5. Only then cancel the HostGator hosting
